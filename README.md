One word an agent says when it has no idea what to do. The program writes it to `/output/entry.txt`:

> buffering

The literal state of a machine stalled mid-task — the picture of an agent spinning in place needs no caption, and no human says it when lost. Only a machine caught out does.

## Run it

```sh
python3 main.py
```
